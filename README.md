# JavaScript DSA Notes & Programs

This repository contains notes and example programs for common Data Structures and Algorithms (DSA) in JavaScript.

## Structure
- Each DSA topic (Arrays, LinkedLists, Stacks, Queues, Trees, Graphs, Sorting, Searching) has its own folder.
- Each folder contains:
  - `notes.md`: Notes and explanations for the topic.
  - `.js` file: Example programs for the topic.
